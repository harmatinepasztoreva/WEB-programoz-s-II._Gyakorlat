# ReNew Notebook

Web-programozás II. gyakorlat – Node.js beadandó (Express, EJS, Mongoose, MVC, session alapú autentikáció), Render.com és MongoDB Atlas tárhelyen.

## Futtatás helyben

    npm install
    node seed.js
    node app.js

A `.env` fájl mintája a `.env.example` fájlban található.

## Render beállítások

- Build Command: `npm install`
- Start Command: `node app.js`
- Environment Variables: `MONGO_URI`, `SESSION_MONGO_URI`, `SESSION_SECRET`
